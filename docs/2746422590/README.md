<p id="b-c04dca528e224c97a7d68f354a6c5cdc"><strong>如何判断菜品是否有核心食材：</strong></p>
<p id="b-b80f9bfb19b147c08a2357d3b7a3488d"><strong>核心食材：</strong>菜品图中存在一个或极少数具有完整形态或典型结构的食材，该食材在画面中面积占比大、位置居中、视觉突出。其他食材仅起装饰或辅助作用，不改变主食材的主导地位。</p>
<p id="b-7c34d59ccc00411a994436e156e72ddc"><span style="color:#FF4A47">【不明确时从严认为是核心食材】</span></p>
<p id="b-490db74c779b40679e7276fcff124baa"><img src="https://km.sankuai.com/api/file/cdn/2746422590/219674010455?contentType=1" width="139" height="104" id="b-c4245add1e9e4b60a04b062d182d030f" alt="原文图片（需学城权限）"></p>
<p id="b-d636afc7c1d54271a2b834a18d02b091"><strong>非核心食材：</strong>在有核心食材存在的菜品中，起装饰或辅助作用的食材。</p>
<p id="b-8a67097f9972439c832e0961030d9b2e"><img src="https://km.sankuai.com/api/file/cdn/2746422590/219674170035?contentType=1" width="111" height="111" id="b-40d18d1c40c54ea899e9e02ebf3f8a48" alt="原文图片（需学城权限）"></p>
<p id="b-49e42e615d064e66b866e30dacfbf96f"><strong>无核心食材：</strong>没有任何一个食材在面积、位置、造型上明显突出到可称为“主食材”，比如：沙拉类、炒菜类、炖菜类、火锅类、炒/拌饭类、炒/拌面类</p>
<p id="b-3800b7bf486b474e82ce9c690573891b"><img src="https://km.sankuai.com/api/file/cdn/2746422590/219668882051?contentType=1" width="100" height="99" id="b-f98742a7afde49cbaba10b71fa2520eb" alt="原文图片（需学城权限）"></p>
<p id="b-bca45a95c37548478a6399963c13c460"><strong>特殊核心食材：</strong>盖浇类菜品中，浇头单独判断，判断如下：</p>
<ul id="b-a0372819fe0441799ed956308a4b813e">
<li id="b-ec59750ec3f445e2a5f4c4dbf6f114f5">鸡腿盖饭，存在主食材“鸡腿”，则判断为有核心食材</li>
<li id="b-1f18f40b6f2f473a8b530c5d10cf6329">辣椒炒肉盖饭，没有主食材，则判断为无核心食材</li>
</ul>
