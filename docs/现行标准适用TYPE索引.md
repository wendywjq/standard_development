<h2 id="b-57ab495e831b41b288154861a98ac3f6"><strong>二、第二阶段 「</strong><span style="color:#00BA73"><strong>DONE</strong></span><strong>」</strong></h2>
<p id="b-820685526c144d93b6e52666a7b319aa">往V3标准体系里面按照代号对号入座输入对应的审核任务流。</p>
<ul id="b-34003c5801a24d679f463ca7861cd360">
<li id="b-6fa28e6494d941698ffc519f7961f9ef">A类「全部」代表全量通用审核任务流。</li>
</ul>
<ul id="b-ee41c74055474b67acec2d08ee2e8d2f">
<li id="b-02a11c8ff9384f6093d04b49cf260fcc">B类「N1-N12」 代表通用审核任务流中的某一区间 。</li>
</ul>
<p id="b-2352511c2f254289af41a9fb1d68904f">所以往V3里面直接输入编号即可找到对应的某一个/块审核任务流。</p>
<p id="b-1032b8bbd9524edabcd94aeaf4174cf4"></p>
<h2 id="b-23d068c1ddca48fab63e21ee5a8108f0">三、第三阶段 <strong>「</strong><span style="color:rgb(0, 186, 115)"><strong>DONE</strong></span><strong>」</strong></h2>

<h2 id="b-15aa81bd47b24984885cc23aad0bd5d5">四、第四阶段 - 「标准整合」</h2>
<h3 id="b-4e968471593349569cc1d48d7d21282d">1、目标与解决方案</h3>
<ul id="b-327c929fa883456191d8a5efe70354cb">
<li id="b-47530ff84589406780dd8347c18af216"><span style="color:rgba(0, 0, 0, 0.5)">判断标准是否使用的前置条件：只要能命中某个任务流映射的一个TYPE就说明该标准在使用，否则为啥要在对应的标准上圈定对应的TYPE。</span></li>
</ul>
<ul id="b-8a80882e15b74775beb183c7d232eaca">
<li id="b-23190199323d461aa5233c9396ac9e6f"><strong>目标</strong>：你所负责拆解的某个业务业态标准，<span style="color:#FF4A47"><strong>对比通用标准分析，剔除归属于通用标准重复性质的内容</strong></span>，专门筛选出专属于该业务/业态标准的细则。</li>
</ul>
<ul id="b-9d0e3e74bb4d4c57b607df333f07e394">
<li id="b-ee14ab4061fa4a66b775187bf7cec0a9"><strong>标准发布位置</strong>：<a href="https://km.sankuai.com/collabpage/1680245774" title="https://km.sankuai.com/collabpage/1680245774" id="b-9e59c059215242b5891c41d5b4e23760">https://km.sankuai.com/collabpage/1680245774</a></li>
<li id="b-088c8a1e892c4a00a796ad5e9e4dbc8a"><strong>注意事项</strong>：能明显识别是一类的，就直接收了汇总吧，预先给标了底色。</li>
</ul>
