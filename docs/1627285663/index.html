个人信息

（订单信息，IM私聊可豁免）

打标

  1. 发布非公开的个人信息，例如：

    • 非公众人物的真实姓名或真实形象，关联以下任一内容：

      • 个人信息（包括生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息）
      • 门牌号
      • 详细住址
      • 不满十四周岁未成年人的个人信息
  2. 重点隐私信息出现即打击：身份证号、护照号、驾驶证号、银行卡、发布他人“自然人的账号和密码”等身份信息

  3. 公众人物隐私谣言的内容，如：公布明星QQ号、家庭住址等

    公众人物（适用于定义3）

    公众人物，是指在一定社会范围内具有知名度、受到公众关注，其言行具有一定公共影响力的人。

    • 文体娱乐人物：演员、歌手、主持人、知名运动员等。
    • 行业及网络知名人士：知名企业家、学者、作家、主播、网络博主等。

  4. 发布他人负面信息，关联下述任一内容：

    负面信息（适用于定义5）

    个人私生活与道德方面（不泛化）：

    出轨与劈腿、做小三、一夜情、私生活混乱、性骚扰、不赡养老人、特殊性取向、特殊性癖、恶意差评、骚扰；

    违法犯罪行为方面（可泛化）：

    盗窃、抢劫、贪污受贿、吸毒与贩毒、杀人、诈骗、老赖、虐待儿童/动物等严重违法犯罪行为；

    工作与职业方面（不泛化）：

    职场性骚扰、不正当竞争手段、拖欠工资。

    • 模糊处理或具体的私人住址

      • 提醒：模糊处理的界限为小区/村子，在xx小区（不必完整到门牌号），比此范围大的如街道、省市区都不属于模糊处理
    • 模糊处理或具体的电话（用手机号后四位代替完整手机号）

    • 真实姓+名

      真实姓+名判断方式举例（适用于定义5）

      一般不认为是姓名：

      1.叠字：韩韩 秋秋 梅梅

      2.小xx、大xx、老xx、阿xx：小风、阿伟、大潘、老徐

      3.姓+职位：吕总、张老师、王总监

      一般认为是姓名：

      指出是姓名（注意，如果明确后面跟的不是姓名，则不属于此范畴，例如“这个人叫小花”）：这个人叫xxx，姓名xxx，name xxx

  5. 涉及无法验证是否获得他人同意，发布他人“自然人的账号和密码”“病史和健康状况”“金融信息”“通信信息””婚姻家庭信息“”护照号“等身份信息的，需打标
  6. 基于公司数据安全要求，审核到公司内部办公和审核基地场景，需打标

豁免

  1. 公众人物相关的公开信息不打击

  2. 对私人信息内容进行遮盖处理

    • 身份证国徽面、信息内容已打码、模糊化处理
    • 明显娱乐化、非真实身份信息可通过
  3. 需向社会求助而曝光的隐私内容, 如寻人/寻物启事等。
  4. 曝光内容中非主体出现他人肖像, 如非私域账号中的生活照 对话头像等
  5. 单纯发布手机号或内容中包含手机号，但无明确曝光他人隐私的意图，不打击，注意对应type是否有“营销导流——联系方式”标签，如果有的话仍需结合案例判断是否打标
